Generated by `node scripts/generate-components.cjs` from the production registry and Zod schemas. Tests compare this entire file and check that all production component exports are registered. Edit behavioral descriptions in registry.ts, not this generated file.

Native composition: 1920x1080 at 30 fps. Fonts/styles/motion come from design/tokens.ts. Key information stays inside 5% title safe and above the bottom 12%. Use local Sequence frames and match duration props to the Sequence. Content must be sourced independently; demonstration numbers are not episode facts. JSON Schema does not express every custom/refinement rule: read each behavioral note as part of the contract.

## Scene transitions

Use sceneTransition(spec) in a direct TransitionSeries.Transition child between TransitionSeries.Sequence scenes. Crossfade uses fade(); map-to-graphic-wipe uses wipe(from-left); dip-to-dark uses a custom presentation whose opacity is zero for both scenes at the midpoint. Put a colors.background surface below the series. Transition overlaps shorten the sum of scene durations; account for them explicitly. No transition may exceed either neighboring scene.

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "properties": {
    "kind": {
      "type": "string",
      "enum": [
        "crossfade",
        "dip-to-dark",
        "map-to-graphic-wipe"
```

## Map infrastructure (React-only, not storyboard layer props)

- PlateStage: plate (local metadata name), camera (CameraPath function), optional geo/screen React nodes and extraAttribution string. Creates projection context and automatically displays attribution. Geo children transform with the plate; screen children keep screen-sized text. Every frame checks coverage/magnification.
- PlateSequence: plates string array, camera, optional transitionAt number/number[], transitionFrames number/number[] (default 30), geo/screen and extraAttribution. Transition entries must match plates.length - 1. Active geo projection switches halfway through each plate crossfade.
- GeoSvg: children React nodes and optional SVG style, inside PlateStage geo. Internal coordinate wrapper, not an independent storyboard layer.
- TextFrame and InfoFrame: internal layout/animation wrappers used by registered components; do not emit them as storyboard component types.

See docs/maps.md, docs/text-layers.md, docs/infographics.md and docs/end-screen.md for projection, sizing, placement and publishing details.
