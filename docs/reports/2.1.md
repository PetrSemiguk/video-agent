## Built and decisions

- `studio/src/design/tokens.ts` is the single source for v1 semantic colors, UI
  surface, eight muted polity colors, typography, spacing, safe zones, radii/halos,
  motion and plate grade controls. Headline: local Barlow Condensed Bold; body:
  local Inter including italic. Three OFL pairings remain on the review sheet;
  each added font has a license row and adjacent upstream OFL notice.
- Minimum production text is 26 px at 1080p. Cities/rivers are 30 px; region caps
  are 44 px in Barlow Condensed. The type-scale sheet shows 26/34/44/64/100/140.
- Title safe: 5%; labels and focusOn framing reserve the bottom 12% for playback
  controls/captions. Entrance offsets are included in the label bottom clamp.
- Region fill reduced 0.35 -> 0.20; outside dimming reduced 0.55 -> 0.24. Labels
  retain their terrain halo. Attribution uses a lighter, more compact UI surface.
- Attribution text was 18 px. The requested smaller overlay conflicts with the
  hard 26 px minimum: text is now 26 px while box padding/background were reduced.
  Attribution is secondary at the bottom edge, exempt from key-information placement.
- Motion defines 30 fps, 10/18/30-frame standard timings, 120-frame default river
  draw, 8-frame stagger, standard Bezier curves, spring and demo timings.
- Removed hardcoded colors from the legacy MapLibre A/B composition. The automated
  source audit permits literals only in tokens and debug/QA files, as the roadmap
  allows. Debug views retain their diagnostic styling.
- Python reads `plateLookJson`, a JSON string in tokens.ts, without executing TS.
  This string survives Prettier unchanged. Removed the duplicate grades.json.
  `dark` is v2; `dark_v1` retains reproducible v1; `neutral` remains available.
- Grade v2 applies a smooth 12.5% land midtone gain and a monotonic exponential
  highlight shoulder (knee 0.48, scale 0.65), retaining hue. The feathered sea mask
  excludes water from this adjustment. Ocean tint/multiply and vignette stay v1.
- Default hillshade is 0.65. Refreshed China and Europe production plates plus
  metadata, preserving projection extents and dimensions. `china-east-hs05` is a
  legacy stable identifier: its metadata now correctly records 0.65, grade v2.
  Explicit old A/B plates (hs0, hs09, central-europe) were not regenerated.

## Measured grade verification

Both comparisons reconstruct v1 with hillshade 0.50 and v2 with 0.65 from the same
licensed BMNG/terrain cache. A separate grade-only measurement holds hillshade at
0.50, isolating land lift and sea preservation. Values use normalized image RGB
luma, not scene-linear photometry. Fully masked sea excludes feathered coast edges.

| Metric | China | Europe |
|---|---:|---:|
| Land midtone pixels sampled (v1 luma 0.06–0.35) | 4,921,437 | 3,673,533 |
| Median grade-only land lift | 12.5% | 12.5% |
| Fully masked sea pixels | 2,290,057 | 3,627,700 |
| Maximum grade-only sea RGB difference | 0 | 0 |
| Mean sea RGB difference including new hillshade | 0 | 2.41e-10 |
| Land luma p99, v1 -> v2 including hillshade | 0.4330 -> 0.4423 | 0.3266 -> 0.3607 |

The p99 can brighten below the highlight shoulder; highlight compression is not
claimed for all land. A 1,000-level grayscale-ramp test checks monotonicity, finite
output, neutral hue and lower white-point brightness. A separate test checks exact
sea preservation and the 1.125 midtone ratio. Sea preservation is tested directly,
not inferred from a whole-image brightness statistic.

## Environment deviations and reproduction

The CLI's esbuild configuration loader cannot read a parent directory in this
Windows sandbox. `studio/scripts/render-design-review.mjs` uses the installed
Remotion APIs with explicit Rspack, ANGLE, concurrency 1 and matching codec/color
options. An existing PNG rejected truncate-on-open despite permitting r+; stills
are now rendered to buffers and existing review files updated through r+. The
video is rendered to a fresh v1 path and copied to the required canonical path.

The default uv cache and pytest temp/cache paths also denied access. Final checks
used an ignored workspace uv cache, no dependency sync, no pytest cache provider
and a workspace basetemp. No ACLs or permissions were changed.

From pipeline:

```powershell

uv run --no-sync python -m vap.geo.grade_review
```
