## Built

Four exported components and strict Zod props schemas live under
`studio/src/components/text/`, with public exports in index.ts:

| Component | Schema | Content limits |
|---|---|---|
| LowerThird | lowerThirdSchema | title 64, optional subtitle 96 |
| SectionTag | sectionTagSchema | text 32, displayed in caps |
| BigDate | bigDateSchema | integer year 1–9999, optional BCE/CE, caption 80 |
| KeyFact | keyFactSchema | statement 120, emphasis 24 |

All render paths parse props. Empty/whitespace-only and multiline/tab content,
unknown props, wrong types and excessive lengths fail with field paths. KeyFact
requires its emphasized substring exactly once, case sensitive. It preserves the
rest of the sentence and colors the emphasized span using a semantic color.

Each schema accepts semantic color, placement and a bounded duration. Entry and
exit use motion.frames.base (18 frames) and standard out/in easing. The local first
and final frames are fully transparent. BigDate counts deterministically from
fromYear (default 0) to the target over motion.frames.slow (30 frames); reverse
counts and seeking work without stateful timers. Zero is only an animation origin,
not an accepted target historical year. No locale-dependent date separators.

All styling, dimensions and timing come from design tokens, including the new
textLayer block. Barlow Condensed Bold and Inter remain local; text sizes are
32/34/44/48/140 px. Boxes have a 1120 px maximum width, wrap long/unbroken words,
and never clip, truncate or shrink type. Defaults place content inside 5% safe
margins and above the bottom 12%; flow placement supports a parent-managed layout.

Added `docs/text-layers.md` with the exact prop contracts, limits and commands.
Added a fontsReady promise to the existing font loader so browser layout checks
wait for actual local faces before measuring.

## Dependencies, sources and decisions

- Pinned Zod **4.5.4** as a direct dependency using npm, matching its already
  installed Remotion transitive version. Lockfile changes only declare that root
  dependency; no other package versions changed. The installed Zod LICENSE is MIT.
- Research used the installed package metadata/license and the
  [official Zod schema API](https://zod.dev/api). Behavior is tested against the
  pinned installed version rather than inferred from a newer documentation version.
- No new data/media/font/model sources were used; no licenses.md addition needed.
  The demo reuses the approved China v2 plate and PlateStage attribution overlay.
  Demo text illustrates components and is not a sourced episode script.
- The limit sheet is **1920x2160** rather than a 1080p four-up: this preserves each
  block's actual 1120 px width and native font sizes. The roadmap does not prescribe
  sheet dimensions. Demo remains 1920x1080.
