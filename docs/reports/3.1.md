## Implementation and deviations

- `normalize.py`: years/decades, quantities with separators/units, eras, ordinal
  centuries and abbreviations. Includes a regression for a comma after a year.
  These are prose heuristics; ambiguous quantities/names still need script review.
- `chunk.py`: remove headings/simple Markdown, preserve paragraphs and original
  sentences, split oversized sentences at words. Default 240 normalized characters
  bounds generation while retaining normal narration sentences; reject a single
  oversized token rather than lose text. Sandbox: six chunks, two paragraphs.
- `tts.py`: lazy GPU model load once on first miss; per-chunk settings/voice/model
  hash cache, seed+index, mono 24 kHz PCM16 and sample-accurate JSON manifest.
  Cache stores raw watermarked float WAVs; malformed/wrong-rate entries regenerate.
  A complete cache hit does not load torch/model. GPU cleanup runs on exit/error.
- Join with 250 ms sentence / 600 ms paragraph gaps and 5 ms fades. Attenuate only
  when peak exceeds 0.98 to prevent PCM clipping. No amplification/limiter/LUFS
  normalization. This output safety adjustment followed initial QA finding single
  clipped samples in the .5/.7 files; rebuilding from float caches corrected them.
- Manifest: original/normalized text, paragraph, params, seed, cache key, sample
  and second spans (end exclusive), pauses, reference hash, versions, pinned model,
  gain, output hash, latest metrics and matching initial generation measurements.
- `benchmark.py`: serial comparisons, exact cache rerun/hash checks, finite/rate/
  clipping checks and actual Perth detection; evidence in benchmark.json.
- `docs/voice.md`: CLI, parameters, cache, measurements and recording ownership/
  license/consent rule. Model caches are ignored workspace paths; explicit shell
  environment overrides are honored. No real person's reference was cloned.

Final review corrected `1644,` being read as a quantity and losing punctuation.
Normalizer cache version was incremented; WAVs were rebuilt with corrected text.
Benchmark resume rejects outdated normalized text. Initial generation metrics

No whisper, lexicon, silence trimming, explicit pause markup or two-pass loudnorm
