## Implementation

- `vap.align.transcribe`: isolated GPU worker, decode mastered WAV to 16 kHz,
  transcribe each exact manifest chunk with word timestamps, add global offsets.
  English, temperature 0, beam 5, no source prompt, no previous-text conditioning,
  VAD disabled. Collect the generator fully before writing recognition JSON.
  Persist pinned model, package versions, options, CUDA capability, timing and
  sampled driver memory. Cache recognition only for matching audio hash, model,
  options and chunk spans.
- `vap.align.match`: monotone Levenshtein sequence alignment on normalized lexical
  forms. Preserve original script words/spelling; expanded numbers or abbreviations
  map to the union of recognized spans. Context normalization handles units and
  St.; merge Whisper's separate `2` and `,000` before normalization. Case,
  punctuation and hyphens do not create false errors. Existing pronunciation
  respellings are applied consistently.
- `vap.align.words`: verify script/WAV hashes, current normalized text, sample/
  second contracts and ordered spans. Output every original word with global
  index, original text, chunk/paragraph/section/sentence ids, start/end and status;
  sentence/paragraph spans have half-open word-index ranges. Include provenance,
  runtime, mismatch evidence, affected chunks and repair history. Reject invalid
  recognition timing. Missing/substituted words get null times rather than invented
  timestamps. Extra recognized words appear in issues. Complete exits 0; unresolved
  exits 2 with reviewable JSON; invalid inputs/worker failures exit nonzero.
- `--fix`: retain original inputs; change only affected chunk seeds (+100003 modulo
  2^32), regenerate through isolated `vap.align.repair`, reconstruct/master the
  whole stem and re-align. Maximum three repair rounds plus initial recognition.
  Unaffected raw-cache keys stay unchanged. Require the same owned/licensed cloned
  reference and hash; never switch a built-in voice during repair. Final JSON
  points to the actual repaired audio; later times and mastering gain may change.
- Parent does no GPU inference. Synchronous subprocess exit, not just torch cache
  clearing, guarantees Whisper allocations are gone before TTS loads and vice
  versa. CTranslate2 allocations are outside torch's allocator.
- `vap.align.qa`: independent whole-waveform RMS-rise detection and reproducible
  ten-word random sampling. No timestamp correction is applied to improve results.
  Added 16 test cases and voice documentation for CLI/schema/repair behavior.

### Selective repair on a controlled omission

Created a **separate copy**, muted the first 0.65 s and faded the splice; this is
an artificial QA fault, not an observed defect in the production voice sample.
Whisper heard “of China ...”; alignment identified missing `Look`, `at`, `a`, `map`,
all in chunk **0**. `--fix` changed seed **42 -> 100045**, generated only chunk 0,
and reused the other **5/6** raw cache entries. The next Whisper worker matched all
78 words: **one repair round**, no remaining issues. Original input/fault files
were preserved. Repair generation: 5.087 s; TTS model load: 10.902 s. The final
mastering and full reconstruction also passed the step 3.2 checks.

Bounded failure is tested with a worker stub: persistent omissions stop after
exactly three repair calls/four recognitions and keep unresolved null timings.
Hallucination/extra-word detection is unit-tested; the actual audio fault example
tests omission detection, not a naturally occurring hallucination. ASR mismatches
remain **candidates for review**, not proof of TTS error.

### Ten random words versus waveform

Seed **33**, ten sampled original words, independent **5 ms RMS / 2 ms hop** onset
detection. Median absolute distance **33.5 ms**, maximum **52.5 ms**. Exact indices,
words and timestamps: `docs/reports/3.3/onset-check.json`; plotted windows inspected
in `studio/out/voice-3.3-verified/onset-check.png`.

**Measurement limit:** these are distances to the nearest acoustic energy-rise
landmark, not independently annotated phonetic word boundaries. Connected speech
and internal syllables can make a landmark ambiguous; the numbers must not be
reported as proven word-alignment ground-truth accuracy. The ten rows were sampled
without cherry-picking. Waveform/ASR markers remain visible for editorial review.
