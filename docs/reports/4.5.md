## Built

- `pipeline/src/vap/episode.py`: the requested `build <slug>` command with
  `--stage voice|align|preview|render|all` (default `all`). A stage includes its
  predecessors; `all` and `render` reach the same final output. All subprocesses
  finish before the next stage starts. Existing GPU workers retain their process
  ownership boundaries.
- Voice uses the existing synthesis/mastering worker with canonical episode
  script/audio paths and defaults or optional `voice.job.json` settings. Owned
  reference audio and final per-chunk seed overrides remain supported. The pilot
  reuses its approved 17-fragment raw cache without loading TTS on the GPU.
- Alignment writes canonical `episodes/<slug>/audio/words.json` / raw recognition.
  Require complete alignment, current script/WAV hashes and positive ordered
  original-word times; unresolved recognition stops the build. The wrapper does
  not silently edit narration, force timestamps or run an automatic TTS repair.
- Preview creates a runtime storyboard under `studio/out/episodes/<slug>/`,
  binding fresh canonical WAV/words. It leaves the authored storyboard and its
  historical report references intact. Existing schemas, acoustic sync and
  every-frame camera preflight run in the existing renderer. Exact first-frame
  stills plus complete narration captions make the preview sheet.
- SHA-256 stage keys include inputs/settings, relevant Python/Studio code,
  lock/config files, installed tool/package versions and actual local media.
  `studio/scripts/episode-inputs.cjs` resolves schema-checked used plates, registered
  B-roll and local fonts before cache lookup. All cached output hashes are checked;
  changed or missing outputs rebuild even when their timestamps look current.
- Successful stage state is saved atomically. Failed work is not cached. Logs
  append per stage and `build-summary.json` describes the latest invocation with
  statuses/timings. Errors exit nonzero with stage name and log path.
- A global exclusive `studio/out/.episode-build.lock` rejects simultaneous builds,
  including different slugs. It records PID/start time and is removed after normal
  success/failure. A killed process can leave a stale lock; the README explains
  checking owner/workers before manual removal. No automatic lock stealing.
- Extended the existing render helper with per-stage `--metadata` and
  `--video-only`, so an existing successful preview is reused when encoding MP4.
  Final MP4 replaces its predecessor only after encoding a sibling partial file
  successfully. Existing manual/default and `--stills-only` paths remain available.
- README now has **Make an episode**: reviewed inputs, exact commands, all stages,
  output/log locations, cache behavior, failure recovery and sequential-job rule.

## Decisions and open questions

checks avoid repeating valid work. Authored storyboards are mandatory from preview
onward and are not generated by this wrapper. Runtime copies use current canonical
timings instead of mutating approved sources or historical report JSON. Existing
selective repair remains an editorial recovery tool rather than an implicit build
side effect. No force/upgrade/publish/agent-layer feature was added.

No unresolved acceptance failures or required user decisions remain. Stop here as
the roadmap directs: stage 5 (agent layer) has not started.
