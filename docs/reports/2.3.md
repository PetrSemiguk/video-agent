## Built

Five reusable components, public TypeScript prop types and strict Zod schemas are
exported from `studio/src/components/info/index.ts`. Every render parses props.
Unknown fields, wrong types, nonfinite/out-of-range numbers, empty/multiline text,
too-long labels and invalid collection lengths are rejected.

| Component / schema | Contract |
|---|---|
| BarCompare / barCompareSchema | 2–5 signed bars, 48-character labels, optional 12-character shared unit, 0–2 decimals, per-bar semantic color |
| TimelineBar / timelineBarSchema | Ordered span with 1–5 markers; integer years -9999..9999 excluding 0; labels 48; BCE/CE and per-event color |
| NumberedList / numberedListSchema | 3–5 sequentially revealed items, 80 characters each; semantic number color |
| RecapCards / recapCardsSchema | 2–4 cards in two columns; title 32, body 80; per-card semantic color and staggered reveal |
| StatCounter / statCounterSchema | Signed/from-to count, label 80, optional unit 12, 0–2 decimals, semantic color |

Titles are capped at 48 characters; numeric values/from values at ±1 trillion.
Shared duration: 69–1800 frames, default 180; demo slots are 120 frames. These are
explicit validation budgets rather than silently shortened text or numbers.
Minimum duration allows five 8-frame staggered reveals, their entrance and exit.
Placement defaults to center, with upper-left/lower-left/flow options inherited
from TextFrame; safe margins and the bottom 12% reservation remain intact.

All visual values are design tokens, including the new infoLayer block. Components
reuse TextFrame, local Inter / Barlow Condensed, motion easing and timings.
Typography stays at 26–88 px, without scaling, truncation or clipping. Bar growth,
playhead and counter settle over 30 frames. List/card items reserve layout space
and reveal in order. All animations derive from the local frame and support seeks.

Added `docs/infographics.md` documenting every prop, numeric/text budget, layout
choice and reproduction command; this is scoped to 2.3 rather than the full 2.4
component catalog.

## Numeric and layout decisions

- Bar domains include zero, and signed bars grow from the same zero baseline.
  Labels wrap above tracks; values have their own column. All-zero data uses a
  0–1 reference domain with zero-width fills. Subpixel values remain subpixel;
  there is no false minimum fill. Midpoint labels can add one decimal place to
  represent half-steps (including 0 / 0.5 / 1) instead of rounding to an endpoint.
- Numbers use explicit `Intl.NumberFormat("en-US")`, fixed display precision and
  grouping; rounded negative zero is normalized. Year labels use ungrouped digits
  and explicit BCE/CE, independent of host locale. Precision rounds displayed
  values; callers choose appropriate units/precision for their data.
- Timeline years use a private ordinal to omit historical year zero from elapsed
  distances: 1 BCE -> ordinal 0, 1 CE -> ordinal 1. Input/display year zero is
  excluded. Events are sorted on a copy, not by mutating input.
- Each timeline event has an aligned track and separate date/label row under the
  common span/playhead. Coincident and tightly clustered dates therefore retain
  separate markers and labels without horizontal collision heuristics or dropped
  events. Endpoint markers stay within their tracks.
- Values capped at ±1 trillion fit a full negative, grouped two-decimal number on
  one line at the chosen native font size. Larger values fail explicitly.
- Sheets are **1920x4560**, preserving each component's actual 1120 px width and
  native typography. The roadmap does not prescribe sheet dimensions. Each block
  is independently checked to fit the 1080p safe height; tall sheet rows do not
  hide blocks that would be too tall for video.
- Samples are explicitly synthetic/illustrative. No new data/media/font/model
  source is used: the demo reuses the approved China plate and its existing visible
  attribution. No licenses.md changes or package installs were needed.
