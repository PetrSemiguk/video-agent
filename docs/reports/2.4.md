## Research and decisions

- [Official YouTube Help](https://support.google.com/youtube/answer/6388789), checked
  2026-11-04: end-screen overlays belong in the final 5–20 seconds, support up to
  four elements at 16:9, and require a video at least 25 seconds long. Placement
  is configurable; the help page gives no universal fixed pixel zones. Our right
  reservations are a project design choice, not claimed platform restrictions.
- At 1920x1080 reserve video rectangle **(1104,162,640,360)** and subscribe circle
  bounding box **(1320,630,240,240)**. Left text stays in x=96..856 and above the
  bottom 12%. The production EndCard burns in no fake YouTube controls or QA boxes.
  Real elements must be placed/previewed in Studio when publishing; no external
  publishing action was taken. Full rationale is in `docs/end-screen.md`.
- Read official [TransitionSeries documentation](https://www.remotion.dev/docs/transitions/transitionseries)
  and [custom presentations](https://www.remotion.dev/docs/transitions/presentations/custom),
  then checked the installed 4.0.539 types/implementation. Installed only
  `@remotion/transitions@4.0.539` and its required shapes dependency at the same
  version. Existing Remotion packages were not upgraded.
- Pexels' [license](https://www.pexels.com/license/) permits commercial video use.
  The [official video 1851190 page](https://www.pexels.com/video/the-sun-illuminating-earth-s-surface-1851190/)
  identifies the current creator as **Ingrid**, marks the video Free, and describes
  Earth-from-space animation. Added its licenses.md row BEFORE download/use.
  Generic/incorrect candidate page URLs and some download URLs returned 403/404;
  none was bypassed. The verified public original CDN object returned 200.

## Built

- **TitleCard**: map screen layer with optional kicker/subtitle, semantic accent,
  entrance/exit, fixed local typography and explicit lengths 80/120/32.
- **EndCard**: exactly 600 local frames at 30 fps, steady final hold with entrance
  but no exit fade; left title/subtitle limits 48/96, reserved right side.
- **BRollClip**: approved local manifest asset ID only, no arbitrary path/URL props;
  bounded trim/duration; slow scale 1 -> 1.06, muted proxy and visible unscaled
  source chip. An sRGB SVG filter shares plate saturation/exposure/gamma. Arbitrary
  footage does not receive an invented terrain shade or land/sea mask; matching is
  to the base plate color treatment, not a claim of pixel-identical map processing.
- **Transitions**: crossfade via fade(), map-to-graphic wipe via wipe(from-left),
  and a custom dip presentation with both scenes transparent at midpoint. Explicit
  dark surface under the series; 24-frame overlaps and token easing.
- **Showreel**: every production layer appears, including region/river/place-label
  map overlays, all four text layers, all five infographics, B-roll and the new
  cards. Five overlaps subtract 120 frames from a 1320-frame series; EndCard holds
  separately from frames 1200–1799. Total exactly 1800 frames / 60 seconds.
- **Registry/catalog**: 16 production components with schemas, purpose, when to use
  and behavioral constraints. `docs/components.md` is generated from the registry
  and actual Zod input contracts; defaults and nested constraints are included.
  Custom refinements/GeoJSON rules are explicitly documented alongside the JSON
  contracts because they cannot be represented fully in JSON Schema.
- Added runtime schemas to RegionHighlight, RiverLine, PlaceLabel and
  MapAttribution so their catalog describes validated actual render inputs. Map
  geometry/timings are checked; river cumfrac must match coordinates and run
  nondecreasing from 0 to 1. Place names now have a 40-character budget, credits
  512. Existing processed map examples validate and rendering style is preserved.
  Map infrastructure, internal wrappers and diagnostics are documented separately,
  not exposed as invented storyboard layer types.
- All new visual values come from tokens.ts; no new fonts/models/data sources.
  B-roll is illustrative animation, not historical/geographic evidence. Graphics
  statistics and timeline markers are illustrative rather than sourced episode facts.
