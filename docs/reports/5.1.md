## Built

- `.claude/skills/geo-episode/SKILL.md`: file layout, stage order with the two user approvals, commands, what the build enforces,
  what is forbidden, and a table of where each rule lives. About 90 lines, with links instead of copies.
- `docs/episode-format.md`: length, structure, word budget, map-first writing with examples, script markup and a checklist before
  asking for approval. Added to the reference list in `AGENTS.md`.

Facts in both were checked against the code: `[pause s]` from 0 to 30 s, the 0.60 s and 1.00 s pauses and unspoken headings
(`vap/voice/chunk.py`, `docs/voice.md`), the 2 s shot minimum (`voiceSync.minShotFrames`), and the build's motion and speed limits. 160 wpm
matches the pilot: 182 words in 67.6 s is 162 wpm.

## Decisions

- **The roadmap's 1,900-2,200 words** is kept. At 160 wpm that is 11.9-13.8 min before pauses, which fits 12-14 min.
- **Chapters are described as future work.** Step 6.4 builds them, and music, subtitles and thumbnails are likewise marked as not existing yet,
  so that an agent does not look for them.
- **Added beyond the request:** a word budget per part for a 13-minute episode (2,080 words). It is my starting point, not a measured value.
