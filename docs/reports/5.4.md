## Built

### `ArrowAdvance` — the missing component the step asks for

A single advancing arrow: a shaft that grows from its origin, tapering from `advanceArrow.taperStart`
of full width to full width, with one head at the tip. It is deliberately not `RouteLine`:

| | `RouteLine` | `ArrowAdvance` |
|---|---|---|
| Reads as | a course that is travelled | a movement of force |
| Shaft | thin, constant width | broad, tapering |
| Direction | small arrows repeating every ~280 km | one head, at the tip, moving |
| Data | `vap.geo.route` output with `cumfrac` | a plain lon/lat path, measured at render time |
| Credit | its own mandatory `credit` | none of its own; the course is the episode's |

- `studio/src/components/map/ArrowAdvance.tsx`, schema in `map/schemas.ts`, tokens in
  `advanceArrow`, registered in `registry.ts` and in the storyboard `layerSchema`.
- `measurePolyline` was added to `studio/src/geo/line.ts`, so a plain path can be sliced like a
  sourced river. It falls back to equal spacing on a degenerate path rather than dividing by zero.
- **Classification.** It joins `geoLayerTypes`, because it draws inside the plate's transformed
  container. It does **not** join the new `naturalEarthLayers`: its geometry is the episode's own
  course, so it must not pull a Natural Earth credit onto the frame. That split is new in this
  step; before it, every geo layer credited Natural Earth.
- **Claims.** It is in `ALWAYS_FACTUAL`: an advance arrow asserts that someone moved this way, with
  or without a label, so the storyboard layer needs a claim id from `facts.md`.
- `style: "dashed"` says on screen that the course is approximate, which the catalog names as the
  honest default for an advance drawn from a narrative rather than a mapped route.

Tests (`ArrowAdvance.test.ts`): measurement by length rather than vertex count, the degenerate
path, the shaft stopping short of the head, the head's position and angle, the schema's limits, and
that the claims rule catches it.

### Two agents

- `.claude/agents/scene-builder.md` — builds one component end to end: component, schema, registry,
  catalog and Python schema regeneration, classification, claims, tests, a still. It starts by
  trying **not** to build, must change no existing component's behaviour silently, and may not
  invent geography.
- `.claude/agents/episode-qa.md` — judges a built episode shot by shot against the evidence the
  repo can already produce (review stills, camera and credit audit, episode audit, mobile sheets,
  motion, rhythm, `ebur128` loudness) and returns PASS / PASS WITH NOTES / FAIL with a fix list. It
  fixes nothing itself, and must say what it could not judge.
