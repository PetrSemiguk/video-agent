## Built

### `.claude/agents/scene-builder.md`

Builds one component end to end: component, zod schema, registry entry, the regenerated catalog and
Python schema, classification, claims, tests and a still it has to look at. It starts by trying
**not** to build, may not change an existing component's behaviour silently, and may not invent
geography.

### `.claude/agents/episode-qa.md`

Judges a built episode shot by shot from the evidence this repo already produces — review stills,
the camera and credit audit, the episode audit, mobile sheets, motion, rhythm and `ebur128` — and
returns a verdict with a fix list. It fixes nothing itself and must say what it could not judge.

### `ArrowAdvance` — the component the step names

A single advancing arrow, distinct from `RouteLine`:

| | `RouteLine` | `ArrowAdvance` |
|---|---|---|
| Reads as | a course that is travelled | a movement of force |
| Direction | small arrows every ~280 km | one head, at the tip, moving |
| Data | `vap.geo.route` output with `cumfrac` | a plain lon/lat path, measured at render time |
| Credit | its own mandatory `credit` | none; the course is the episode's |

`measurePolyline` in `studio/src/geo/line.ts` lets a plain path be sliced like a sourced river.
The component joins `geoLayerTypes` but **not** the new `naturalEarthLayers`, so its own course
pulls no Natural Earth credit onto the frame; that split did not exist before this step. It is in
`ALWAYS_FACTUAL`: an advance asserts that someone moved this way, label or not.

**The still earned its place.** `out/arrow-check.png` showed the first version reading as dashed:
the shaft was drawn as 14 stacked strokes of growing width, and anti-aliasing left a hairline of
casing at each of the 13 joints. Reordering casings before fills did not help. Since dashes are
reserved for "this course is approximate", a shaft that looks dashed is a correctness bug, not a
blemish. The taper was dropped for a single constant-width stroke, with the reason recorded in the
`advanceArrow` token. A true taper needs one filled polygon, which would then have to solve dashing
some other way.

## The step's own acceptance

### (a) `scene-builder` delivered a component on request

Given a brief for a retreat — narration saying a force pulled back from a line it had held — and
told that `ArrowAdvance`, `RouteLine` and `RegionHighlight` cannot express it, the agent delivered
`ArrowRetreat` with its schema, registry entry, classification, claims rule, 8 tests, a
`RetreatCheck` sheet and `npm run still:retreat`.

It did not take the easy reading. Rather than running `ArrowAdvance` backwards, which would read as
a fresh attack in the other direction, it argued for a different behaviour: **the head stands on
the line fallen back to from the first frame and never moves, the shaft collapses onto it, the
ground let go stays behind as a faint dashed trace, and a bar across the course marks the line held
and is released as the withdrawal starts.** It rejected a bare receding front line because the
narration names both a body of troops and a line reached, and a bar alone cannot say who went where.
Its sheet puts a real `ArrowAdvance` on a parallel course in the same frame for contrast.

Verified independently: `npm test` 155 passed, `npm run lint` clean, and
`git diff studio/src/components/map/ArrowAdvance.tsx` contains only this session's taper removal —
the agent changed no behaviour of the advance arrow, and imported its exported helpers instead.
