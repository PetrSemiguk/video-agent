## Built

- `studio/src/episode/Episode.tsx`, registered as **Episode** in Root.tsx. Default
  props contain the sandbox storyboard, checked step 3.3 words, frame plan and a
  public-relative WAV path. Other callers can pass their own JSON props.
- `metadata.ts` / `wav.ts`: calculateMetadata fetches the **actual** WAV bytes,
  parses mono PCM16 RIFF format/data chunks and computes ceil(samples*fps/rate).
  Verify complete positive ordered word spans and exact WAV SHA-256/duration
  agreement. Fetch declared plate metadata, compile the frame plan, verify camera
  coverage and inject serializable prepared props. RF64, float/compressed WAV,
  truncated/malformed data and mismatching alignment fail rather than guessing.
- `plan.ts`: strict explicit frame windows, one per authored shot/layer in order;
  contained layer windows and complete audio-frame coverage. Actual Sequence
  durations replace component duration defaults and are validated by each
  production schema. EndCard's exact 600-frame contract remains enforced.
- `camera.ts`: adapters for all six existing presets, one global C2 camera
  timeline and local shot wrappers preserving absolute camera time. A first
  inherited hold/drift/focus path gets an initial plate-centered pose derived
  from existing safe-area/coverage values. No independent camera animation look
  or CSS timing was introduced. Preflight checks every scene frame, including
  outgoing extensions; PlateStage repeats its existing render-time checks.
- Shots become TransitionSeries scenes containing **PlateStage**, or
  **PlateSequence** for an animated change to a different plate. Geographic
  RegionHighlight/RiverLine layers and screen components are routed to their
  correct projection contexts and rendered through local named Sequences using
  the production component registry. Inline GeoJSON remains the v1 contract.
- Outgoing animated scene duration is extended by exactly its transition
  overlap; TransitionSeries subtracts that same amount. Subsequent explicit
  absolute scene starts and the audio timeline stay fixed. One **Html5Audio**
  sits outside the transitions, at unity volume, without repeats/trim/stretch.
- `map/AttributionContext.tsx` plus a small MapAttribution integration: suppress
  inline overlays only inside Episode's combined-credit scene scope, and render
  one visible union of both active scenes' credits above all transitions. Include
  plate, Natural Earth, explicit credit-layer and approved B-roll credits with
  identical strings deduplicated. Ordinary standalone component behavior is
  unchanged. This fixes unreadable overlapping credit strings found in the
  first different-plate/river transition inspection.
- `prepare-episode.mjs`: validate local authoring inputs/files/hash; stage only
  the approved WAV into ignored public/episodes/tts-test/voice.wav; emit ignored
  out/episode-props.json. No arbitrary repository path is fetched by the browser.
- `render-episode.mjs`: existing Rspack Node API, explicit ANGLE/concurrency 1,
  H.264/AAC, JPEG frames, yuv420p, limited-range BT.709. Six illustrative review
  stills, metadata and full MP4. `--map-smoke` supplies an in-memory alternate
  existing plate plus existing Yellow River data and renders overlap/post-overlap
  checks. Authored storyboard is preserved.
- Added npm scripts **prepare:episode** and **render:episode**, tests and the
  assembler section in docs/storyboard.md. No authoring schema version change.

## Scope decision: explicit timing input

The 4.1 example contains phrase anchors, while **automatic phrase resolution is
explicitly a 4.3 item**. To render it in 4.2 without starting that work, added
`episodes/_sandbox/tts-test/assembly.json`: an explicitly authored preview frame
plan supplied through `timing` props. It schedules six shots at frames
**0, 101, 239, 358, 469, 581**, ending at **743**; layer starts are local.
All three authoring anchor forms remain unchanged in storyboard.json.

The assembler requires already prepared frame windows. It does not search phrases,
apply label lead, snap cuts to pauses, choose a minimum-shot policy, automatically
fill gaps with drift or generate the 4.3 first-frame/text sheet. This deliberate
input boundary lets 4.3 produce the same timing contract later. Basic window
integrity checks are needed to render an explicit plan safely, not a claim of
automatic synchronization acceptance. Sandbox text/facts remain demonstration
content, not a publication-approved pilot.

with an FFT correlation search over +/-100 ms and checks lag <=1 sample and

**0.7061**, consistent with equal-power mono-to-stereo conversion; stereo
integrated level remains essentially the stem's -16.09 LUFS. Lossy AAC output is
not claimed bit-identical. No final-mix gain, music or stage-6 normalization was
added. Original WAV and checked authoring/alignment files were not overwritten.
